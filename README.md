# Designly Creative OS — AI alapú kreatív platform

Sötét, fantasy-stílusú, önállóan futó egyoldalas weboldal.

## Fájlok

| Fájl | Leírás |
|---|---|
| `index.html` | A közzétett oldal. A háttérkép be van ágyazva, külső fájlfüggés nincs. |

## Funkciók

- **Hero** — sodródó háttér, mozgó füst/köd és parázs, villogó kék és sárga holló-szem, forgó kelta motívum, felvillanó és felfelé szálló rúnák.
- **Navigáció** — ragadós menü, sima ugrás a szakaszokra, mobil hamburger menü.
- **Szakaszok** — szolgáltatások, lépések, árazás, GYIK, stúdió, CTA, lábléc.
- **Huginn AI panel** — bezárható és újra előhozható asszisztens doboz.
- **Akadálymentesség** — „csökkentett mozgás" beállításnál az animációk lekapcsolnak; minden kép kapott leírást, minden gomb típust.

## Közzététel

**Settings → Pages → Source: Deploy from a branch → Branch: `main` / `(root)` → Save**
